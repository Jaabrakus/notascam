# Player races, weapons and armor

Open `index.html` to browse and filter all 420 PNG entries. There are 13 existing-art race designs, 375 ordered equipment states, and 32 additional cutouts from the existing enhanced sheets. All preserve their original native visible heights.

`source-resolution/` contains the larger race/sheet cutouts for later 3D work. `native-sheets/` contains all 279 validated local enhancement DMI sheets, preserving the original metadata, alpha masks and animations.

The race and enhanced-sheet artwork was extracted without repainting its source RGB. The game equipment catalog uses the earlier local enhancement pass. Minor source edge residue is documented in the independent reports. No files were installed into the running game.

This folder excludes rejected redesigns and earlier mask candidates. `catalog.json` records every delivered file and hash.

# Faithful equipment base catalog

All 19 selected modern material families are complete: 375 ordered equipment states, one first occupied facing/frame per state. These PNGs preserve the validated processed DMI cell exactly, including original alpha, height, position and 64×64 canvas. They use local lighting enhancement; they are not newly AI-redrawn designs.

Each `<family>/catalog/` contains the state PNGs and `index.json` with ordered state names, selected native cell indices, animation metadata and file hashes. No animation states were omitted or merged. The full animated DMI files remain in `../../processed/Gear64/Human/`.

Eight families also contain four objects extracted from the previously checked enhanced reference sheets in `<family>/approved-sheet-art-v2/`: bonehide, dragonhide, spidersilk, leather, spiderfang, dragonfang, cloth and magic. All 32 source-resolution cutouts retain source RGB exactly. Their separate final PNGs match the corresponding native visible heights and bottom baselines. The magic skull staff uses the corrected `-v3` filename recorded in the batch report.

The extractions preserve the actual reference-sheet objects. Detached weapon handles and effects remain as drawn. Some cloth edges retain minor gray residue; these are documented source/masking limitations. `approved-sheet-art-v1-held/` and the superseded skull crop are retained review candidates, excluded from the 407 current deliverables.

No art was generated, repainted or procedurally redesigned for this faithful catalog. No runtime installation or 3D conversion was performed. Earlier standalone design candidates are separate and held.

Validation and source mappings: `../../../_meta/faithful-equipment-batch.json`. Independent extraction review: `../../../_meta/existing-sprite-cutout-review.json`.

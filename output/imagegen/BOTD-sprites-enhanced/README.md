# Detailed enhanced sheet artwork

The selected collection is **[detailed-artwork/index.html](detailed-artwork/index.html)**. Download the complete pack as **[detailed-enhanced-artwork.zip](detailed-artwork/detailed-enhanced-artwork.zip)**.

It contains **60 full-resolution equipment pages across 19 families**, covering 375 source item states, plus the existing detailed references for 13 races. Fifty equipment pages are newly drawn with the built-in image tool; ten previously checked detailed pages are retained.

**[Individual cutouts and height-matched exports](detailed-artwork/exports/index.html)** are included: 388 transparent full-resolution cutouts and 763 original-height PNGs. Each size export matches the original visible height and bottom anchor, with proportional width. Equipment size exports use one source-facing view per state; animation and fitting remain separate.

The large artwork is retained for the later 3D work. Native/local passes and earlier experiments remain in their existing folders; the detailed-artwork collection is the current selected target.

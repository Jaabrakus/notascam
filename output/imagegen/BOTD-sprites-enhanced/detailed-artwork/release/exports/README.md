# Detailed artwork exports

Open `index.html` to browse 388 full-resolution transparent cutouts: 375 equipment states and 13 races.

`game-height/inventory/` contains 375 variants matching the original 32-frame inventory icons. `game-height/player/` contains 375 variants matching the original 64-frame Human equipment references. `game-height/races/` contains 13 race variants matching each original visible height. Width is proportional and can vary.

The full-resolution cutouts preserve the detailed artwork colors before mechanical resizing. Height and bottom baseline are checked for every smaller PNG. These are size exports; equipment fitting, animations and runtime installation are separate tasks.

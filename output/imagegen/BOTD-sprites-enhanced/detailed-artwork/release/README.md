# Detailed enhanced sheet artwork

Open `index.html` to browse the large plates. Currently 19/19 weapon and armor families are ready, with 60/60 equipment pages. The existing race plates cover all 13 base races.

This collection uses the detailed AI-enhanced sheet style selected by the user. Images retain their full generated resolution for later 3D work. Native/local reshading previews and rejected candidates are not listed. Original-height game exports remain separate.

`manifest.json` records accepted pages and hashes. `prompts/` retains the prompts for new built-in image-tool artwork. Page metadata carries complete state names when embedded labels are abbreviated.

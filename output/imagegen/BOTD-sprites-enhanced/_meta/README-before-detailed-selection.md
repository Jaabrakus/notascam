# Player races, weapons and armor

Open **`players-gear/final/index.html`** to browse the finished selection. The clean package is **`players-gear/players-races-weapons-armor.zip`**.

The delivery contains **13 race designs, 375 ordered equipment states, and 32 additional cutouts from the existing enhanced sheets**. Existing race/sheet foreground colors are preserved before proportional resizing, and all sprites match their original native visible heights. Larger source-resolution cutouts are included for later 3D work.

The package also includes **279 locally enhanced native DMI sheets** with all **74,394 frames**. Independent validation preserved their original alpha masks, height, metadata, timing, state order and unused cells. Standalone equipment PNGs use one occupied facing/frame per state; complete animations remain in the DMI sheets.

The faithful extraction used three Sol agents and no new image-generation calls. Rejected redesigns and earlier mask candidates are excluded from the clean package. Minor conservative edge residue in some cutouts is recorded in the review. Original source/game files remain unchanged; outputs are not installed into the running game.

Reports: `_meta/faithful-delivery.json`, `_meta/faithful-races-batch.json`, `_meta/faithful-equipment-batch.json`, `_meta/existing-sprite-cutout-review.json` and `_meta/players-gear-independent-review.json`.

The earlier 669-file inventory and previous experiments remain in this folder as history. The current selection is playable race bases, modern weapons and armor; unrelated items, ropes, separate limbs, FX and legacy cosmetic/status variants are outside this delivery.

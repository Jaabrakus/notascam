## Playing the current app

Select a unit, then tap a tree, mineable tile, loose resource or destination. Use Add tasks to append; Deselect leaves the work running. Set a stockpile in Work, then use Drop off or Unload & resume. Open a unit card's Skills, needs & inventory for carried items. Controls contains the original commands. Some direct actions pause work; check the card for Resume.

Closing saves units and carried inventory. Changed terrain, buildings, dropped stockpile cargo and active world-target queues currently reset on restart.

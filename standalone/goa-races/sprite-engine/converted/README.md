# GOA redraw drafts

Generated with the built-in image generation tool against the approved GOA race reference. Each race has a transparent 64-pixel-cell PNG atlas and frame metadata. Full-resolution results and prompts remain in the saved jobs and redraw-provenance.json.

These are generated animation drafts. Review frame-to-frame scale, gait, feet, and overlay registration before game integration. Grid and file checks do not establish animation quality. The approved first Vampire look was retained with its unintended ground wings removed.

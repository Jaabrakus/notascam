# Female race and hybrid walk drafts

80 separate appearances: ten races, each with a base and seven hybrid forms. Each PNG has twelve 64×64 cells: South, North, East and West columns, and neutral, step A and step B rows. Playback uses 0, 1, 0, 2 at 200 ms per phase. The DMI exports contain the same four-phase movement sequence.

Open `index.html` to compare appearances and play the walk cycles. The sample copy is `Dungeon Master Sample/GOA Female Races and Hybrids.html`; the named PNG, DMI and metadata exports are packaged in `Dungeon Master Sample/GOA Female Walk Animations.zip`.

Selected artwork uses corrected.png when present, otherwise generated.png. Prompts and generation provenance remain beside each source. Race, Female and appearance are included in every exported filename. FrogMan uses the shortened-arm revision. Tail-bearing hybrids retain directional tails.

These are generated walk drafts. Automated checks cover playback, frame layout, distinct poses, clipping, foot alignment and export naming. Visual gait approval and equipment fitting remain pending. Attacks, sleep, limb loss and game integration are separate work.

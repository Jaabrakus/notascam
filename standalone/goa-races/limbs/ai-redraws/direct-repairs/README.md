# Current direct repairs

The current repaired sheets are `elf-ashen-injuries64-v1.png` and `orc-werewolf-injuries64-v1.png`, with matching DMI files. Each contains seven standing states in four directions, using 64×64 frames.

The four high-resolution `*-arms-v1.png` and `*-legs-v1.png` source sheets were redrawn with the built-in image tool from the approved identities. Exact prompts and provenance are stored alongside them. Final packing preserves surviving RGB samples; it does not recolor bodies, splice heads or warp proportions.

Rows: Normal, NoLeftArm, NoRightArm, NoArms, NoLeftLeg, NoRightLeg, NoLegs. Columns: South, North, East, West. Whole back-view frames were reordered where AI swapped anatomical sides. Approved standing profiles are reused when the missing far arm is fully occluded.

Validation: 56 standing frames checked; transparent background RGBA cleared; NoLegs has no pixels in the foot band; disconnected background fragments excluded. Walking animation has not been generated or verified for these injury states. These assets are not installed into the live game.

Preview: `Dungeon Master Sample/Blond Ashen Elf and Orc Werewolf - Limb Sheets.html`.

The older `hybrid-reuse/` batch was rejected and is not a final asset set. Other hybrid repairs remain unfinished.

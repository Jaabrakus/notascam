# Dungeon Master Sample

- [GOA Races and Hybrids.html](GOA%20Races%20and%20Hybrids.html): updated race designs, hybrid appearances, new base walk cycles and corrected north-facing wings. Includes animation playback and64px export.
- [GOA Updated Races and Hybrids.zip](GOA%20Updated%20Races%20and%20Hybrids.zip): packed PNG atlases, metadata and supplied movement DMI files, including seventy hybrid walk drafts. Injury work is handled separately.
- [GOA Hybrid Walk Animations.zip](GOA%20Hybrid%20Walk%20Animations.zip): seventy race-and-hybrid named walk sheets, 64px PNG/DMI exports, labeled review sheets, updated standing references and generation provenance.
- [GOA Vampire Flight - North Fixed.png](GOA%20Vampire%20Flight%20-%20North%20Fixed.png): approved first Vampire flight design with only its north-view wing layering corrected.
- [DemonFly - North Wings Fixed.png](DemonFly%20-%20North%20Wings%20Fixed.png), [GargoyleFly - North Wings Fixed.png](GargoyleFly%20-%20North%20Wings%20Fixed.png), [Gargoyle-eyes - North Wings Fixed.png](Gargoyle-eyes%20-%20North%20Wings%20Fixed.png): full sheets with foreground wing panels in rear views.

- [GOA Universal Armory.html](GOA%20Universal%20Armory.html): shared weapons, shields, helmets and wearable armor across the updated races and hybrids, with holding/walking previews, fitting presets and equipped-sprite exports.
- [Launch GOA Universal Armory.command](Launch%20GOA%20Universal%20Armory.command): opens the armory using a local server.
- [Universal Gear and Weapons.csv](Universal%20Gear%20and%20Weapons.csv): source-backed design/material list.

- [Launch GOA Sprite Converter.command](Launch%20GOA%20Sprite%20Converter.command): import sprites, prepare a GOA-style redraw job for this Codex chat, detect the finished result, and export a transparent sprite atlas. Double-click to launch.
- [GOA Sprite Converter.html](GOA%20Sprite%20Converter.html): portable version; conversion jobs download as ZIPs to attach here. See `../standalone/goa-races/sprite-engine/README.md` for the workflow.

- [GOA Race Sample.png](GOA%20Race%20Sample.png): the six generated race drafts, four standing views each.
- [GOA Attack and Casting Sample.png](GOA%20Attack%20and%20Casting%20Sample.png): original GOA body animation frames for punching, kicking, weapon attacks, throwing, casting, and hurt reactions.
- [GOA Gear Sample.html](GOA%20Gear%20Sample.html): self-contained interactive equipment fitting preview using the existing 16-angle, 3D-derived gear assets. Open in a browser.
- [GOA Held Sword Sample.png](GOA%20Held%20Sword%20Sample.png): original GOA sword composed with the original body in four directions, standing/walking and attack frame examples.
- [GOA Held Sword Demo.html](GOA%20Held%20Sword%20Demo.html): starts with GOA's original held sword. Toggle Walk or Attack poses to animate the original body and weapon.

The attack/casting sheet uses original GOA source frames, not generated animation. The new race sheet remains a standing visual draft; those races do not yet have the GOA attack/casting animation frames. Equipment fitting is still a prototype. Existing game assets are unchanged.

The editable preview sources and detailed notes remain in `../standalone/goa-races/`.

Female race and hybrid walk drafts: [viewer](GOA%20Female%20Races%20and%20Hybrids.html) and [PNG/DMI exports](GOA%20Female%20Walk%20Animations.zip). Ten races, eight appearances each, with 64×64 cells.

[Human combat action sample](GOA%20Human%20Combat%20Sample.html): one-handed sweep defaults for spears, blades, axes, hammers and maces; separate bow/arrow and staff action drafts. [PNG/body/metadata exports](GOA%20Human%20Combat%20Samples.zip).

[Universal animation library](GOA%20Universal%20Animation%20Library.html):97 reusable humanoid clips, four-direction Human mapping previews, and an editable joint map. [Clips and sprites ZIP](GOA%20Universal%20Animation%20Library.zip).

[Idle weapon holds](GOA%20Idle%20Weapon%20Holds.html):16 four-direction weapon/shield comparisons, with the slower spear jab in the interactive viewer.

# Drawn animation library

Scope selected by the user: the full animation library for every race.
Method: newly drawn sprite frames using the existing race artwork as identity references
and the supplied Human action sheet as the pose/style reference. Existing rigs and art
remain available as references; their renders are not the requested final drawing method.

First sheet in production: male Orc sword swing, four directions and four action phases.
Generated drawings require inspection for consistent anatomy, direction, frame alignment
and native-pixel suitability before being labeled usable game atlases.

This folder is a work in progress, not a completed race animation library.

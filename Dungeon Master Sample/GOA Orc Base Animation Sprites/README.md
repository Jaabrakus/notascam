# Orc base animation sprites

Current focus: Orc body-only animation frames. Appearance variants and other races are paused. Weapon/ shield holding and action poses belong in the body sheets; equipment and effects stay separate.

The user selected the original native in-game Orc as the master. The larger drawn Orc used for skin tests is not a replacement master. Both reference PNGs are exact file copies. Twelve original 64px idle/walk cells are also copied exactly under references/native-source-frames/.

The 97-action manifest records the existing library coverage; it does not claim those Orc sprites are drawn. New frame artwork is pending. The drawn reference remains an unregistered draft.

Current new artwork lives in `new-drawn-attacks/`: separate anatomical left/right punches and kicks, with short legs and four facings. These generated drawings are drafts, not native-size, pixel-locked game exports. The approved front-kick motion is saved under that folder's `references/user-approved-front-kick.png`. The assembled `body-only-library-v1/` is retained for reference but was rejected as final artwork.

# Base Body Holding Poses

Three human base-body pose sets, drawn using built-in imagegen. Characters wear only charcoal shorts. Weapons, shields and worn armor are absent; hands retain the intended equipment-holding stances.

Each folder includes original artwork, a 256×64 sheet, four individual 64×64 transparent frames, a 4× nearest-neighbor preview, generation prompt and manifest. Direction order: South, North, East, West. Feet are registered at (32,61).

These are standing pose drafts. Walking, attacks, equipment attachment layers and sixteen directions are not included.
